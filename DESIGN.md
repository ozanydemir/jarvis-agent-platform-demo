# Interface design

This demo adapts the shared **engineering routing desk** system to a bounded assistant runtime. Warm paper and compact ledger rows keep the interface calm; green, amber, and red are reserved for policy decisions.

The signature view is an authority path: request, intent classification, policy check, simulated adapter, and evidence receipt. No UI element implies unrestricted computer access. On narrow screens, the path becomes a vertical audit sequence.

Every action is synthetic or simulated. The demo has no operating-system authority, private integrations, or production credentials.

A credited, licensed stock photograph provides hardware context only. No real device is connected, addressed, or controlled by the demo.
